# Troy's Ruleset — Archived

Personal routing rules previously collected and generated for proxy clients. **This repository is archived and no longer maintained.** Historical files remain available, but accuracy, compatibility and remote dependencies are not guaranteed. No daily-update promise applies to this archive.

Older README references to `Reject.conf`, `RejectDomain.conf`, `AppleDomain.conf`, `Qobuz.conf` and `ChinaASN.list` do not correspond to files retained in this snapshot and are no longer presented as downloads.

## Use as a reference

Review rules and upstream sources before copying anything into a current configuration. Match the target client's syntax and policy-group names, and back up working settings first. This archive supplies neither a proxy service nor a maintained subscription.

For the related configuration collection, see [Troy](https://github.com/Trovoy/Troy), whose maintenance is also paused. The historical Actions workflow and scripts are preserved for context, not as a supported automation service.
